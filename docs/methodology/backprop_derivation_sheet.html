5. Gradient direction

The prediction (0.462) is below the target (2), so e = ŷ − y is negative. Every parameter currently pushes ŷ upward when it increases (∂ŷ/∂c = 1, ∂ŷ/∂v = h > 0, and w, b act through tanh′(z) > 0 and v > 0), so every gradient has the sign of e, i.e. negative. Gradient descent moves opposite to the gradient, so all four parameters increase, ŷ rises toward 2 and the loss falls. c gets the largest step because ŷ depends on it directly; w and b are scaled down by tanh′(0.5) = 0.786 and v by h = 0.462.

6. Numerical check (done in C++, not required by hand)

Central differences ∂J/∂θ ≈ [J(θ+ε) − J(θ−ε)] / (2ε), ε = 1e-6. Absolute differences from the analytic gradients: w 1.1e-10, b 1.1e-10, v 5.3e-11, c 1.1e-10, all ≤ 1e-5 (results/csv/backprop_gradient_check.csv). Loss after 100 further steps with η = 0.1: 1.7e-20 (results/plots/backprop_loss.png). The loss falls quickly at first, then geometrically, because one sample with four parameters can be fitted exactly; the curve flattens only at floating point round-off.
