Assumptions & method
  • Constant k, A, q; insulated lateral surface; steady state.
  • ke = (kA/h)[1 −1; −1 1], fe = (qAh/2)[1 1]ᵀ, assembled into a tridiagonal K.
  • T(0), T(L) imposed by symmetric elimination (known values moved to the RHS).
  • Errors are evaluated at element midpoints using FE interpolation Th = N₁Te+N₂Te+1.
  • Nodal values of 1D linear elements are exact for this problem, so nodal-only error would wrongly suggest zero error.
